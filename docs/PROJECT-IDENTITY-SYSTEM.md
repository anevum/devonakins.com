# Project identity system — November 4, 2026

**Status: DESIGN EXPLORATION / SOURCE IMPLEMENTATION PROPOSED.** These are first-party vector identity *concepts*, not a trademark audit, approved final logos, merged release, or deployed site change.

## Design rule

Every named project should have its own recognizable mark and bespoke lettering, not a reused typographic preset. A consistent site-wide presentation grid is acceptable; copying one emblem or neon treatment across unrelated businesses is not. Preserve accessible project names, understated motion, strong mobile contrast, and clear descriptions of actual software status.

## First implementation increment

- **Merit:** geometric, copper-gold proof/check motif and modular path-drawn wordmark. Verification, not claimed certification.
- **Rhen:** cyan, flowing-ribbon R and custom letterforms. Language experimentation, not a released compiler. Do not confuse with financial Vesper sources.
- **Squelch:** magenta-violet angular audio/signal wordmark. Correct current name; no Phatcake references. Touch-first digital four-deck DJ direction; the mark does not imply an implemented DAW.
- **DevonStation:** muted botanical-green orbital D emblem. Separate personal operations system, not Anevum or Cristy's records.
- **IdeaFlow:** clear cyan-blue infinity/loop emblem. Collaborative idea capture without pretending its incomplete features are live.
- **Business operations:** intentionally *not* branded as a fictional product; retain the descriptive text card.

The portfolio header, hero copy, statuses, routes, and accessible card structure remain unchanged. SVGs use original paths rather than raster concept-image screenshots or external fonts.
