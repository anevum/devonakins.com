## Design rule

Every named project should have its own recognizable mark and bespoke lettering, not a reused typographic preset. A consistent site-wide presentation grid is acceptable; copying one emblem or neon treatment across unrelated businesses is not. Preserve accessible project names, understated motion, strong mobile contrast, and clear descriptions of actual software status.
